# Background music

Drop 5 to 15 calm instrumental tracks here (`.mp3`, `.wav`, `.m4a` or `.ogg`).
Each video picks one automatically. To force a track for an episode, add `"music": "file-name.mp3"`
to the episode, or `"music": "none"` for no music.

Free sources that allow use in monetized YouTube videos:
- YouTube Studio > Audio Library (filter by mood: Calm, Sad, Inspirational)
- Pixabay Music (pixabay.com/music)

Upload them in GitHub with **Add file > Upload files** while you're inside this folder.

Until there's music here, videos use a soft generated ambient pad.
